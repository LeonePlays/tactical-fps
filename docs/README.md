# TACTICAL FPS

**FPS Tático 3D | Browser Game | Em Desenvolvimento**

---

## Sobre o projeto

**TACTICAL FPS** é um projeto independente de jogo de tiro tático em primeira pessoa, desenvolvido para navegadores.

Inspirado em jogos clássicos como Counter-Strike 1.6 e Rainbow Six: Vegas, o projeto busca combinar partidas rápidas, movimentação tática, mapas tridimensionais e diferentes modos de jogo.

O desenvolvimento está organizado de forma modular, visando evolução contínua e manutenção do código.

## Estado de desenvolvimento

**Status:** Em desenvolvimento  
**Plataforma-alvo:** Navegadores modernos  
**Dispositivos-alvo:** Computadores e dispositivos móveis  
**Versão do documento de design:** GDD 1.4

> As funcionalidades descritas abaixo representam o planejamento do projeto e não necessariamente estão disponíveis em uma versão jogável.

## Funcionalidades planejadas

- Sistema de movimentação e câmera em primeira pessoa.
- Ambientes 3D internos e externos.
- Mecânicas de partidas por equipes e rodadas.
- Personagens controlados por inteligência artificial.
- Multiplayer em tempo real.
- Campanha com narrativa original.
- Mapas multiplayer derivados de regiões da campanha.
- Sistema de contas e progresso persistente.
- Interface responsiva para diferentes dispositivos.

## Modos de jogo

### Multiplayer
Partidas táticas em mapas compactos, com diferentes modalidades e objetivos.

### Campanha
Experiência narrativa com cenários maiores, progressão e missões próprias.

## Arquitetura

O projeto prevê uma arquitetura modular, com separação entre interface, lógica de jogo, renderização 3D, serviços de backend e persistência de dados.

As tecnologias e a estrutura definitiva serão documentadas conforme a implementação evoluir.
